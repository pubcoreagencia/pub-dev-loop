# PUB Prototype — Preview Runtime

## Goal

Provide a Lovable-like live preview loop while keeping Git, task execution, 9Router and PDL ownership unchanged.

## Runtime modes

- `PROTOTYPE_PREVIEW_MODE=public` (default): starts the app locally and exposes it through a Cloudflare Quick Tunnel, producing a public HTTPS `*.trycloudflare.com` URL.
- `PROTOTYPE_PREVIEW_MODE=local`: keeps the preview on localhost for local-only development.

Quick tunnels are intentionally ephemeral and public. The URL is generated by Cloudflare and changes when the tunnel is recreated. Do not use a quick-tunnel URL as a production application endpoint.

## Environment

```text
PROTOTYPE_PREVIEW_MODE=public
PROTOTYPE_PREVIEW_COMMAND=npm
PROTOTYPE_PREVIEW_ARGS=run dev -- --host 0.0.0.0 --port {PORT}
PROTOTYPE_PREVIEW_STARTUP_TIMEOUT_MS=60000
PROTOTYPE_TUNNEL_STARTUP_TIMEOUT_MS=30000
CLOUDFLARED_COMMAND=cloudflared
```

## Lifecycle

```text
Prototype prompt
  -> persistent session workspace
  -> agent/9Router
  -> validation + commit
  -> start/reuse dev server
  -> quick tunnel
  -> PREVIEW_READY
  -> SSE to browser
```

The first prompt starts the dev server and tunnel. Later prompts reuse the same session workspace and runtime so the application's state evolves prompt by prompt.

## Process boundary

Worker and API are separate processes. Prototype events therefore use PostgreSQL persistence + `NOTIFY`/`LISTEN` as the cross-process transport, then the API fans them out through SSE.

## Security

Preview URLs are public by design. Do not expose sensitive services, credentials, internal admin endpoints, or real customer data through Prototype Mode. Use mock data by default. Public URLs are for demos and validation, not production authentication boundaries.

## Future stable URLs

For persistent named previews, replace Quick Tunnel exposure with Cloudflare named tunnels or Sandbox `exposePort()` behind a controlled domain. Cloudflare currently recommends `sandbox.tunnels` for public URLs; named tunnels provide stable hostnames while quick tunnels are intended for development/demos.
